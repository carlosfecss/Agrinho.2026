# Agrinho.2026
Agricultura Sustentável
Sobre o projeto

Este projeto consiste em uma página web desenvolvida com HTML e CSS que apresenta informações sobre agricultura sustentável. O objetivo é explicar, de forma clara e acessível, a importância de práticas agrícolas que conciliam a produção de alimentos com a preservação do meio ambiente.

A página foi criada com foco educacional, reunindo informações sobre o conceito de agricultura sustentável, algumas de suas principais práticas e os benefícios que ela proporciona para a sociedade e para os recursos naturais.

Objetivos
Apresentar o conceito de agricultura sustentável;
Destacar práticas agrícolas que contribuem para a preservação ambiental;
Demonstrar os benefícios sociais, econômicos e ambientais desse modelo de produção;
Aplicar conhecimentos de desenvolvimento web utilizando HTML e CSS.
Funcionalidades

O site possui:

Página responsiva para diferentes dispositivos;
Menu de navegação fixo;
Seção explicativa sobre agricultura sustentável;
Cards informativos com imagens ilustrativas;
Lista dos principais benefícios da agricultura sustentável;
Efeitos visuais para melhorar a experiência do usuário.

Conteúdo apresentado

O projeto aborda algumas práticas importantes da agricultura sustentável, como:

Rotação de culturas;
Uso eficiente da água;
Agricultura orgânica.

Além disso, destaca benefícios como a preservação do meio ambiente, a conservação da biodiversidade, a redução da poluição e a produção de alimentos mais saudáveis.

Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, permitindo uma boa experiência de navegação em computadores, tablets e smartphones.

Considerações finais
